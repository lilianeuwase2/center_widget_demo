# Center Widget Demo 
Center is a flutter layout widget that positions its single child in the middle of the available space both horizontally and vertically 
## The attributes 
**child**
- the widget that get centered 
- in the demo the LoadingCard() is changed tp EmptyCartCard() and the new card appears in the middle
- this is to choose what the user sees in the middle of the screen 

**widthFactor**
- set to default null , so the center is as wide as the parent allows 
- and this is used so that the center is in the middle of the parent 

**heightFactor**
- set to default null , so the center is as tall as the parent allows 

## Real-world use case 
A loading screen 

##  How to run 

1. make sure Flutter is installed 
2. clone the repository 
  * git clone https://github.com/lilianeuwase2/center_widget_demo.git 
  * cd center_widget_demo
3. Run the app: `flutter run`
